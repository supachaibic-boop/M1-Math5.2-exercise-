# แบบฝึกหัดคณิตศาสตร์ ป.5 เทอม 1 — M1-Math5.2 Exercise

คลังข้อสอบฝึกทักษะคณิตศาสตร์ระดับประถมศึกษา สำหรับเตรียมความพร้อมและฝึกโจทย์วิเคราะห์

## เนื้อหาจากบทสนทนาที่นำเข้ามาแล้ว
- [Level 6 — ข้อสอบ 30 ข้อพร้อมเฉลยและวิธีทำ](level-6.md) : โจทย์ปรนัย 4 ตัวเลือก เพิ่มความยาก 1 ระดับ (เวลาแนะนำ 120 นาที)
- เฉลยอยู่ในไฟล์เดียวกัน แต่แยกส่วนท้ายเพื่อให้พิมพ์ข้อสอบโดยไม่เปิดเฉลยได้

## ขอบเขต
การสนทนาก่อนหน้านี้มีการอ้างถึงข้อสอบต้นฉบับ 50 ข้อและ Level 2–5 ชุดละ 30 ข้อ แต่ข้อความโจทย์และเฉลยฉบับเต็มของชุดเหล่านั้นไม่ปรากฏครบในบริบทที่เข้าถึงได้ จึงยัง **ไม่** นำเนื้อหาที่ไม่สามารถตรวจสอบได้มาเขียนใหม่หรืออ้างว่าอัปโหลดแล้ว

## วิธีใช้
เปิดไฟล์ Markdown บน GitHub พิมพ์ส่วนข้อสอบเพื่อทำแบบฝึกหัด จากนั้นตรวจคำตอบและอ่านวิธีทำในส่วนเฉลย
